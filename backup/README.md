# Backup: the single-file game

`index-11.7.3-single-file.html` is the whole game as one file, exactly as it was
before the code was split into `js/` and `css/` (version 11.7.3).

To go back to it: copy it over `index.html` in the repository root. The `js/`
and `css/` folders are then no longer used.
